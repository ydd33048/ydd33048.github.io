🧰 Meet the Toolbox

The Toolbox is the part of etaHEN most people interact with. Think of it as a control panel that appears over the top of the console's normal interface. It groups everything into short lists, and each entry is either switched on or switched off.

🧩 Plugins, Explained Without Jargon

A plugin is a small extra that adds one specific ability. It is not a program you install in the usual Windows sense; it is a file that etaHEN picks up and loads when the console starts.

The practical workflow is simple. Copy a plugin file into the folder the Toolbox expects, turn the plugin on in the menu, and the new ability appears. If you later decide you do not want it, turn it off in the same menu or remove the file. Because plugins are separate from each other, a misbehaving one can be disabled without touching the rest.

When you collect plugins from different sources, keep a note of which file came from where. Two plugins that do similar things can conflict, and knowing their origin is the fastest way to solve a problem.

🎯 The FPS Counter for PS4 and PS5 Games

This port includes an on-screen frame rate readout that works with both PS4 and PS5 titles. It draws a small number in a corner of the screen, updated continuously, showing how many frames per second the game is producing at that moment.

For most people the number is simply interesting: it tells you whether a game is holding a steady rate or dipping during busy scenes. For anyone comparing graphics settings or testing a plugin, it is genuinely useful data that is otherwise invisible.

The overlay can be switched off at any time from the Toolbox, so it never has to stay on screen while you are just playing.
